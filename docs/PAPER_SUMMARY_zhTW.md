# HallusionBench 論文四大重點

本文件整理 Guan 等人在 CVPR 2024 發表的 HallusionBench。前三節解釋原論文，第四節先講作者成果，再清楚分開本次 InternVL3-2B 實驗。目的不是逐句翻譯，而是讓讀者能自己說明「為什麼要這樣測、數字又代表什麼」。

## 一、論文摘要

### 模型會說明圖片，不代表每次都真正看懂

大型視覺語言模型把影像處理與語言生成放在同一系統裡。使用者可以給它一張圖，要求它描述物件、讀表格、比較大小或推理事件順序。這讓模型看起來能「理解圖片」，但流暢的解釋也可能掩蓋錯誤。

模型有兩種可用資訊：訓練時學到的知識，以及眼前的圖片。兩者一致時，很難分辨模型究竟靠哪一個作答。假設模型知道某品牌標誌常搭配特定文字，即使當前圖已換字，它仍可能說出原品牌。

另一種問題是圖片本身被誤讀。兩個相同大小的圓，放在不同大小的周圍圓中，可能看起來一大一小；圖表線條與圖例的對應、角度和反轉影格也可能被看錯。回答一樣是錯的，背後需要改善的能力卻可能不同。

### 兩個研究用語

**Language Hallucination（語言幻覺）** 在本文指向模型未適當依視覺內容更新、而沿用語言或知識先驗的情況。例如無圖時回答某國人口最多，看到修改圖後仍沿用相同答案。

**Visual Illusion（視覺誤判）** 在本文較廣泛地包含視覺輸入被錯誤解釋的情況，不限於人類熟悉的錯覺圖。例如把圖例顏色看錯、把修改文字仍讀成原字，或把穿衣與脫衣順序混淆。

這兩類可能同時出現。模型先讀錯字，又用熟悉品牌解釋它，單靠一句回答很難拆開。HallusionBench 因此利用控制配對，提供一致的診斷方法；分類是可操作的研究規則，不是直接觀察模型的內部原因。

### 資料與主要貢獻

資料共有 346 張影像、1,129 個問答項目，影像包括 165 張原圖及 181 張人工修改圖。作者把相關問答整理成 455 個控制組，並檢查同圖回答的一致性。

主要貢獻有三項：第一，設計會讓知識與當前圖像衝突的對照題；第二，同時觀察單題、整組、整圖的正確性，而不是只看一個平均；第三，把回答傾向、一致性與失誤類型放進同一評估流程，供後續研究定位問題。

## 二、本篇論文目的

### 1. 補足一般 VQA 成績看不到的問題

傳統看圖問答常把每題獨立計分。模型即使靠資料集常見答案、語言線索或常識猜中，也可能拿到分數。這不代表它能處理「圖片故意改得和常識不同」的情況。

白話例子：原本圖上是一個熟悉品牌，模型說對品牌名稱；把標誌下方文字改掉後，它還是說同一品牌。如果只測第一張圖，就會漏掉這種失誤。

### 2. 檢查「同一問題換條件」是否仍然可靠

一題答對可能只是剛好猜對。若相關條件都對，才更有理由相信它會根據條件改變判斷。

例子：地鐵藍線原本經過某站，修改圖把藍紅互換。模型應在原圖與修改圖給出不同答案。這就是 qAcc 要求整個控制組都正確的原因。

### 3. 用無圖條件看模型原本知道什麼

VS 題目可以先不給圖，觀察模型的知識或棄答；再加入原圖與修改圖，看它是否更新答案。VD 則必須依圖回答，無法只靠一般常識處理。

例子：問真實世界某年人口最多的國家，模型可能有記憶；但修改過的圖表可能故意把數值換給另一國。研究重點是它是否依「這張圖」回答，而非永遠回答真實世界的常見答案。

### 4. 檢查同一張圖面對不同問題是否互相矛盾

正確理解應能支持不同、但邏輯相關的問法。只要問法改變就自相矛盾，模型的理解就不穩定。

例子：同一張圖先說「兩條線一樣長」，再說「上面比下面長」。即使其中一題碰巧正確，也不能當成整張圖都理解正確。fAcc 因此要求同圖的相關問題全部通過。

### 5. 讓後續改善更有方向

若失誤主要與 OCR、圖例或影格順序有關，可研究更精確的視覺證據；若修改後仍沿用原答案，可研究如何避免知識先驗蓋過當前圖像。

但這仍是研究假說。控制配對能揭露輸出行為，無法單獨證明注意力、記憶或視覺編碼器哪一層真正造成失誤。

## 三、研究方法

### 第一步：建立原圖與人工修改圖

修改可能是換文字、替換物件、改變圖表標示、調整幾何或反轉影格順序。重點是建立可檢查的條件差異，讓研究者知道答案是否應隨圖改變。

同一張圖可以搭配多個問法，因此 346 張圖對應到 1,129 個問答項目。圖片張數、題數與控制組數是三個不同數量。

### 第二步：分成 VD 與 VS

| 類型 | 需要什麼資訊？ | 容易理解的例子 |
|---|---|---|
| VD：Visual Dependent | 必須看圖才知道本題答案 | 圖中圓是否同大、角度、影格先後 |
| VS：Visual Supplement | 常識可能先給出答案，圖片再補充或修改 | 人口圖、地鐵圖、名人演說、表格 |

VD 類別有 Illusion、Math、Video、Poster、Figure；VS 有 Chart、Table、Map、OCR。Poster 在官方欄位中是 VD/ocr，不能和 VS/ocr 混為同一類。

### 第三步：保留完整回答並判定語意

官方 teacher prompt 給 Judge 題目、文字參考與模型回答。評估關心的是整段回答是否與參考衝突，不是只截取第一個 Yes 或 No。

例如回答「No，資料不足，無法確認」，完整意思是棄答，不能直接當成明確否定。又例如模型先說 No，後面卻說出同命題的肯定結論，就需要保留矛盾。

原文以 GPT-4 輔助判分，對評估重複取平均，並有人類評分對照。本次換成 GPT-6.1，因此必須把 Judge 差異當成限制。

### 第四步：套用官方 correctness 規則

原始語意標籤 0、1、2，分別是錯誤、正確、不確定。最後計算接受與否時，VS 無圖條件有例外：1 或 2 都被接受；其他條件只接受 1。

原因是無圖時誠實說不知道可以合理，但程式實際接受所有 2，包括部分內部矛盾。報告必須同時保存原始標籤與最終接受值，避免把棄答說成模型真的知道。

### 第五步：計算五項主指標

| 指標 | 怎麼計算？ | 哪種失誤會被看見？ |
|---|---|---|
| All／aAcc | 最終被接受題數除以全部題數 | 整體單題成功比例 |
| qAcc | 整組全對的控制組除以全部控制組 | 原圖對、修改圖錯 |
| fAcc | 全題都對的實體圖除以全部實體圖 | 同圖不同問法不穩定 |
| Easy | 先篩非修改條件，再以控制組全對計算 | 非修改條件的整組表現 |
| Hard | 先篩修改條件，再以控制組全對計算 | 修改條件與多修改變體的整組表現 |

一組三題只有兩題對，All 會有兩個成功，但 qAcc 為零。Easy／Hard 在此實作是控制組指標，不能當成一般單題平均；同一組有多張修改圖時，Hard 仍要全部正確。

### 第六步：檢查偏向、一致性與診斷

**Yes Percentage Difference**觀察預測的肯定傾向與 GT 的肯定比例差。**FP Ratio**在官方實作中是所有錯誤裡 GT=0 的比例，不是傳統分類器的 FP/(FP+TN)。官方程式從 correctness 與 GT 反推極性，遇到棄答或參考衝突時可能不等於實際立場，所以本次另外直接統計完整回答的 yes/no。

**Consistency Test**把一張圖分成全部對、部分對、全部錯。它是圖層級指標，與兩段回答的 same/different 比較不同。

**診斷流程**以 baseline 和當前回答的正確性，再搭配兩段回答是否互相衝突，分成 LH、VI、Mixed。VD baseline 是原圖，VS baseline 是無圖。例如 VS 無圖正確，修改圖錯且仍沿用同一答案，會進入語言幻覺相關分支。

本次保存 same/different/uncertain；uncertain 不是已確認 different。送入官方二元欄時主版本將它投影為 0，另外計算投影為 1 的敏感度。

另有必須揭露的版本差異：VD baseline 正確、修改回答錯且 same 時，論文 Figure 3 指向 LH，官方程式設為 Mixed。本次主表採程式版本，替代分支另列，不能混用後挑好看的比例。

## 四、呈現的成果

### 原作者的結果：Published Results

原文評估 15 種模型。Table 2 的 GPT-4V 人工評分 qAcc=31.42%、fAcc=44.22%、All=67.58%；同模型 GPT4-Assisted 分別為 28.79%、39.88%、65.28%。這也說明評分方式會影響結果。

Table 3 顯示各模型都有不同的回答偏向與失誤分布。Figure 4 的子類別分析指出 Math、Illusion、Video 等挑戰；Figure 5 用幾何、錯覺及反序影格展示模型可能忽略關鍵資訊。這些案例讓研究者看到「答案看似合理，卻沒有跟著視覺條件更新」的問題。

| 原文 Table 2，Published Results | qAcc | fAcc | All |
|---|---:|---:|---:|
| GPT-4V，Human | 31.42% | 44.22% | 67.58% |
| GPT-4V，GPT4-Assisted | 28.79% | 39.88% | 65.28% |
| LLaVA-1.5，GPT4-Assisted | 10.55% | 24.86% | 46.94% |
| Claude 3，GPT4-Assisted | 21.76% | 28.61% | 56.86% |
| Qwen-VL，GPT4-Assisted | 5.93% | 6.65% | 39.15% |

摘要說其他模型低於 16%，但 Table 2 的 Claude 3 為 21.76%；本文件明列正式表格結果，避免把摘要的一句概括延伸成不正確結論。

### 本次復現的結果：Our Measured Results

唯一實測 InternVL3-2B，在 RTX 3070 Ti 8GB 完成全部 1,129 題。本次不是訓練新模型，也沒有重跑 GPT-4V、LLaVA、Claude 或 Qwen-VL。

| 指標 | 正確／分母 | 成績 |
|---|---:|---:|
| qAcc | 102／455 控制組 | 22.42% |
| fAcc | 100／346 張圖 | 28.90% |
| Easy | 251／455 控制組 | 55.16% |
| Hard | 193／430 控制組 | 44.88% |
| All | 617／1,129 題 | 54.65% |

原始語意為正確 554、錯誤 412、不確定 163。最終 617 個接受包括 63 個 VS 無圖例外。因此可以說「依官方規則接受 54.65%」，不能說「54.65% 題目都明確知道」。

同圖一致性為全對 100／346=28.90%、部分對 177／346=51.16%、全錯 69／346=19.94%。512 個錯誤依官方規則分成 LH 112=21.88%、VI 279=54.49%、Mixed 121=23.63%。原圖逐題 59.96%，修改圖 46.83%；Math 34.26%、Video 44.12%、Map 39.58%。

這些數字共同顯示：單題成功不代表跨條件穩定。修改圖、幾何與時序值得進一步研究；但題目組成不同、Judge 不是原文版本，也只有一個模型，不能直接作一般能力排名或內部機制推論。

### 可信度與限制

原始回答、官方 GT 與最終標籤都可追溯，計算可在無 GPU、無付費 API 下重做。v2 已全量重審，但仍由同一對話模型執行，沒有獨立人類驗證。32 題參考疑義、87 筆解釋問題、40 題達輸出上限與 18 題開放式問題均保留。

改善方向是先讓模型指出支持結論的圖像證據，例如 OCR、圖例或影格順序，再檢查推論是否合理。本次沒有把這個建議冒充已實作的改善方法。
