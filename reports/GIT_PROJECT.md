# 本地 Git 專案

此研究資料夾已建立獨立的本地 Git repository，主分支為 main。圖片、模型權重、Python 環境、下載快取、原始論文 PDF 及大型暫存檔均由 .gitignore 排除；.gitattributes 保留檔案原始位元，避免換行轉換破壞 SHA-256。

系統尚未設定使用者的 Git 作者身分，因此本次成果提交使用明確的自動化作者 `Codex <codex@localhost>`，只透過該次 Git 命令指定，不修改使用者全域 Git 身分，也不冒用使用者電子郵件。

尚未指定 GitHub 遠端 repository，未對外發布。正式交接以本地結果、完整性報告與 ZIP 為準。
